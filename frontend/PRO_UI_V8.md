# COPEC3 PRO — UI/UX v8

Cette version applique une professionnalisation transverse du frontend sans modifier les contrats API ni la logique métier.

## Améliorations

- Navigation réorganisée en **Pilotage / Scolarité / Vie scolaire / Finance & RH / Administration**.
- Navigation de l'agent d'accueil orientée directement vers le **Registre des visiteurs**.
- Barre de contexte persistante dans l'espace d'administration.
- Design system transversal : surfaces, tableaux, formulaires, boutons, focus clavier et états interactifs plus cohérents.
- Densité des tableaux et formulaires réduite pour améliorer la lecture et limiter les erreurs.
- Responsive renforcé sur les écrans de gestion.
- Conservation des routes, composants métier, API, exports et workflows existants.

## Principes UX

1. Une page = un objectif principal.
2. Les actions secondaires doivent rester discrètes.
3. Les formulaires utilisent une hiérarchie claire et une validation visible.
4. Les tables privilégient la lisibilité, le statut et l'action contextuelle.
5. Les mêmes composants doivent garder le même comportement dans toute l'application.
